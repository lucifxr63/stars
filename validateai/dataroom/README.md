## Qué es este data room

Este directorio reúne la documentación institucional inicial de **Validus**, el producto de validación de startups de **Scouttech**. Su objetivo es ofrecer una base **clara, honesta y versionable** para conversaciones con inversionistas, aceleradoras, partners y clientes institucionales.

No busca exagerar tracción. Validus está en etapa temprana (**pre-revenue**) y este data room lo refleja con transparencia: lo que ya existe, lo que está en borrador y lo que queda pendiente de validar.

## Para quién está pensado

- **Inversionistas** (ángeles, pre-seed/seed, fondos LatAm) evaluando una primera conversación.
- **Aceleradoras e incubadoras** evaluando admisión o partnership.
- **Partners y clientes institucionales** (equipos de innovación corporativa, programas públicos).

## Principios de este data room

1. **Honestidad sobre hype.** Si no hay revenue, clientes pagos o métricas medidas, se dice explícitamente.
2. **Trazabilidad.** Las afirmaciones se basan en el código y la documentación del proyecto; las estimaciones se etiquetan como tales.
3. **Versionable.** Markdown plano, fácil de revisar en control de versiones y de exportar a PDF/deck.

- `> Pendiente:` — información faltante o por validar.
